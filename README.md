# squat-counter

メイドキャラクターと一緒にスクワットを続ける、iPhone向け記録・育成Webアプリです。Windowsだけで開発でき、iPhoneのSafariから利用できます。

## 初期MVP

- 日々のスクワット回数とメモの記録（ブラウザの端末内保存）
- 1日の目標、達成状況、連続達成日数の表示
- メイド「ルナ」による応援メッセージ
- 累計スクワット回数に応じたメイド・報酬の解放
- 記録履歴の表示と削除

## iPhoneで使う方法

1. このファイル群をGitHub Pages、Cloudflare Pages、NetlifyなどのHTTPSで公開できるWebホスティングへ配置します。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタンから「ホーム画面に追加」を選びます。

ホーム画面から起動すると、通常のアプリに近い画面で使えます。記録データは利用したiPhoneのブラウザ内に保存されます。

## ローカル確認

Windowsでは `index.html` をブラウザで開くだけで画面を確認できます。オフライン動作を含むPWAの確認には、HTTPSまたはローカルWebサーバーが必要です。
